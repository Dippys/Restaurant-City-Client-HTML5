## Blockers

- The 2026-08-23 production snapshot retains three profiles with no Banner and
  no legacy-slot collision evidence; automatic restoration would guess player
  ownership, so these require administrator/player confirmation. One missing
  Wall Tile is present in inventory and is intentionally left alone.
- Legacy parser damage remains visible in the production snapshot: 408 unknown
  inventory rows across 80 profiles and 153 unknown ingredient rows across 31
  profiles. Their small numeric IDs cannot be mapped unambiguously to shipped
  items; preserve them for administrator review rather than auto-renaming.
- Two enabled-player restaurants employ network UIDs that no longer have a
  `UserProfile`. Reassign or remove those two employee rows with the existing
  safe inactive-user repair workflow before final production sign-off.
- Automatic arbitrary restaurant/garden/rating/profile deep-link navigation
  exposes no safe named callback. Those backend/public link kinds remain
  available to administrators, but player creation is intentionally absent now
  that ADR-0023 removed the generic page menu. Automatic in-SWF target
  navigation requires the minimal unsanctioned AS3 change documented in
  `docs/specs/social-share-sources.md`; it was not made. Photo download is now
  implemented separately by ADR-0046.
